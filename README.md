# Responsible Gaming API Portfolio Project

This portfolio project presents a RESTful API designed to support features for responsible gambling, such as setting personal gambling limits and restricting specific games or bet types. The project includes well-structured OpenAPI (Swagger) documentation and business analyst artifacts.

## Key Features

- Limit loss amount by player  
- Limit playtime duration  
- Restrict game types or sports for betting  
- User self-service requests with review by compliance officer  

## Included Artifacts

- Swagger/OpenAPI 3.0.3 specification (YAML format)  
- BPMN 2.0 and UML 2.0 diagrams (draw.io format)  
- Use case documentation and user stories  
- Example JSON events and API requests  

## How to Use

1. Open the Swagger YAML file with [Swagger Editor](https://editor.swagger.io) or Redoc to explore the API endpoints.  
2. Import BPMN/UML diagrams into [[draw.io](https://app.diagrams.net)](https://app.diagrams.net/?url=https://raw.githubusercontent.com/olegustymenko/BA_portfoilio_O_Ustymenko/main/RG_Set%20Limits%20by%20Player_FINAL.drawio
) for viewing or editing.  
3. Review the documentation to understand functional flow and system interactions.  

## Technologies Used

- OpenAPI 3.0.3  
- Swagger UI / Redoc  
- BPMN 2.0  
- UML 2.0
